# English A2 Bot

Telegram-бот для ежедневной практики английского на уровне A2. Спокойный ритм: около 10 минут в день, без стриков, штрафов и напоминаний.

| Когда | Что приходит | Что делает ученик |
|---|---|---|
| ☀️ Утро | 6 новых слов по теме дня: значение, IPA, перевод, 2 примера, словосочетания, подсказка + голосовое с произношением | слушает и повторяет вслух |
| 📖 Обед | История на 120–160 слов с этими словами (выделены) + озвучка, затем 2 вопроса **голосом** | отвечает голосовым → сразу фидбек |
| 🌙 Вечер | Квиз из 5 вопросов (Telegram quiz-poll, проверяется мгновенно) + 2 коротких письменных задания | пишет ответ → сразу фидбек |

**Тема недели.** После выбора языка ученик выбирает тему кнопками:
- 11 популярных тем A2: еда, путешествия, покупки, работа, дом, семья, внешность и характер, здоровье, хобби, город, технологии;
- или 🎲 Mix: новая тема каждый день.

Как работает неделя:
- Неделю весь материал идёт по выбранной теме. У каждого дня своя подтема («At the airport», «Hotels and booking»…), поэтому неделя не однообразная.
- Через 7 дней вечером бот один раз предлагает выбрать следующую тему, выбор начинает действовать со следующего утра. Если ученик промолчит, тема продолжится ещё неделю.
- `/topic` меняет тему в любой момент, сразу и со словами на сегодня.

Фидбек на каждый ответ: что было хорошо, не больше 3 исправлений, естественная версия ответа (можно послушать 🔊), один совет. Объяснения на языке ученика: ru / uk / pl / en.

Пропускать можно всё: вопросы идут по одному, есть кнопка «Skip», всё доступно в `/today`. Если ученик молчит 7 дней, бот один раз пишет «ставлю на паузу, вернёшься — нажми» и больше не беспокоит.

## Почему так устроено (коротко по ресёрчу)

- **5–8 новых слов в день** для A2. Слова даются в контексте и тематически, потом сразу встречаются в тексте. Это comprehensible input: текст почти целиком из знакомых слов плюс новые.
- **Повторение с расширяющимися интервалами.** Слова с 1, 3, 7 и 14 дня назад возвращаются в историю и квиз. Для закрепления слову нужно около 10 встреч (Webb 2007): карточка + текст + вопросы + квиз + повторы.
- **Retrieval practice.** Ученик должен сам произнести или написать ответ, а не только узнать правильный вариант.
- **Фокусированная обратная связь.** Максимум 3 ошибки, в порядке важности: сначала мешающие пониманию, потом ошибки со словами дня. Explicit correction с однострочным правилом: в асинхронном чате это работает лучше, чем recast.
- **Произношение оцениваем честно.** LLM плохо оценивает отдельные звуки. Бот оценивает грамматику, лексику, содержание, и только мягко отмечает слова, которые было трудно разобрать.
- **Reading while listening.** Текст вместе с озвучкой даёт для A2 больше, чем чтение или слушание по отдельности.
- **Без давления.** Никаких стыдящих стриков. Не больше одного сообщения на каждую часть дня. Молчащих пользователей бот ставит на паузу.

## Стек

- **TypeScript + [grammY](https://grammy.dev)**: лучший фреймворк для serverless-ботов.
- **Vercel Hobby** (бесплатно):
  - вебхук `/api/telegram`: бот отвечает 200 сразу, Gemini работает в `waitUntil`, повторные апдейты от Telegram отсекаются по `update_id`;
  - 3 Vercel Cron в день;
  - лимит функции 300 с.
- **Neon Postgres** (бесплатно, 0.5 GB): HTTP-драйвер, пул соединений не нужен.
- **Gemini API** (free tier):
  - урок дня: 1 вызов `gemini-3.8-flash`;
  - проверки ответов, текст и голос: `gemini-3.5-flash-lite`;
  - озвучка: `gemini-3.8-flash-lite-tts`;
  - у каждой роли своя цепочка фолбэков.
- **TTS → MP3 на чистом JS** (lamejs), без ffmpeg. Каждый клип генерируется один раз, дальше переиспользуется Telegram `file_id` для всех учеников.
- **Слова:** 1342 слова A2 из CEFR-J Wordlist. Выданные слова учитываются отдельно по каждой теме и в ней не повторяются.
- **Урок один на (день, тему)** и общий для всех, кто на этой теме. Повторение слов идёт по прошлым урокам той же темы.

## Установка (≈15 минут)

1. **Бот:** [@BotFather](https://t.me/BotFather) → `/newbot` → токен.
2. **Gemini:** [aistudio.google.com/apikey](https://aistudio.google.com/apikey) → ключ. Актуальные лимиты вашего проекта смотрите на [aistudio.google.com/rate-limit](https://aistudio.google.com/rate-limit).
3. **База:** [neon.com](https://neon.com) → New project → скопировать connection string.
4. **Локально:**
   ```bash
   cp .env.example .env.local   # заполнить значения
   npm install
   npm run db:migrate           # создать таблицы
   npm run dev                  # бот на long polling — можно писать ему в Telegram
   ```
5. **Vercel:**
   - запушить репозиторий на GitHub;
   - [vercel.com/new](https://vercel.com/new) → Import;
   - в Settings → Environment Variables добавить те же переменные, включая `CRON_SECRET`;
   - Deploy.
6. **Вебхук:**
   ```bash
   npm run set-webhook -- https://<your-app>.vercel.app
   ```
   После `npm run dev` вебхук снимается, поэтому после локальной отладки запустите эту команду ещё раз.

Прогнать часть дня вручную, так же как это делает крон: `npm run stage -- morning|midday|evening`.

## Расписание

Кроны в [vercel.json](vercel.json) задаются в UTC: `06:00`, `11:00`, `17:00`. Для Варшавы это примерно 8:00, 13:00 и 19:00 летом (зимой на час раньше).

На Hobby-плане Vercel запускает каждый крон раз в день в пределах указанного часа, точность ±59 минут. Для такого бота это нормально. Если нужно точное время:

- заведите бесплатные задания на [cron-job.org](https://cron-job.org);
- они должны делать `GET https://<app>/api/cron/morning` (и так же `midday`, `evening`) с заголовком `Authorization: Bearer <CRON_SECRET>`;
- кроны из `vercel.json` уберите.

Повторный запуск безопасен: таблица `deliveries` не даст отправить одно и то же дважды.

## Настройки (env)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `TIMEZONE` | `Europe/Warsaw` | граница «сегодня» для уроков |
| `DEFAULT_HINT_LANG` | `ru` | язык переводов и объяснений для новых учеников |
| `INVITE_CODE` | — | закрыть бота: вход только по ссылке `t.me/<bot>?start=<код>` |
| `MAX_CHECKS_PER_DAY` | `30` | проверок Gemini на ученика в день (защита квоты) |
| `INACTIVE_DAYS_BEFORE_PAUSE` | `7` | через сколько дней тишины ставить на паузу |
| `GEMINI_*_MODELS` | см. `.env.example` | цепочки моделей через запятую |

## Бюджет Gemini в день

**Общие вызовы на каждую тему, которую выбрал хотя бы один активный ученик** (от числа учеников не зависят):
- 1 вызов на урок;
- 4 TTS: слова, история, 2 вопроса.

Максимум 12 тем (11 + Mix), то есть до 12 уроков и 48 TTS в день. Если все ученики на 2–3 темах, расход в 2–3 раза больше, чем с одной общей темой.

Вечерний крон заранее готовит уроки на завтра, по 3 темы параллельно.

**На ученика:** около 4 проверок (2 голосовых + 2 письменных) плюс кнопки 🔊 по желанию.

Для группы из 10–20 студентов free tier Flash-Lite хватает с запасом. Если квоту одной модели выбрали, бот переключится на следующую в цепочке.

⚠️ На free tier Google может использовать запросы для улучшения своих моделей. Стоит сказать об этом ученикам.

## Структура

```
api/telegram.ts          вебхук (secret token → waitUntil → grammY)
api/cron/*.ts            утро / обед / вечер
src/bot.ts               команды, кнопки, приём ответов
src/stages.ts            рассылка частей дня, задания по одному, кэш голосовых
src/lesson.ts            выбор слов, повторение, генерация и валидация урока
src/review.ts            проверка ответа (текст или аудио) → структурированный фидбек
src/gemini.ts            JSON-ответы, TTS, ретраи и фолбэки моделей
src/audio.ts             WAV/PCM → MP3
src/format.ts            HTML-сообщения
schema.sql               таблицы
```

`npm test` запускает юнит-тесты и интеграционные тесты сценариев бота (Telegram, БД и Gemini замоканы). `npm run typecheck` проверяет типы.

## Идеи на потом

- Персональный SRS (FSRS, `ts-fsrs`) по ошибкам каждого ученика вместо общего графика повторения.
- Точная оценка произношения через Azure Pronunciation Assessment для заданий «прочитай вслух».
- Недельная сводка: какие ошибки повторяются.
